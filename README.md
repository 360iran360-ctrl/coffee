# وب‌سایت مهدی پارسا — متخصص فیزیولوژی و حرکات اصلاحی

سایت شخصی و برندینگ «مهدی پارسا» به‌صورت **ایستا** (HTML5 + CSS3 + JavaScript خالص)،
کاملاً **فارسی و راست‌به‌چپ**، همراه با ظاهر سه‌بعدی ملایم و واکنش‌گرا.

این سایت هیچ وابستگی بیرونی ندارد: نه فونت اینترنتی، نه CDN، نه تصویر خارجی،
نه اسکریپت رهگیری و نه فراخوانی API. همه فایل‌ها داخل همین پوشه قرار دارند و سایت
بدون اینترنت هم کامل کار می‌کند.

---

## ۱. اجرای سایت روی کامپیوتر خودتان

### روش ساده (بدون هیچ ابزار)
پوشه پروژه را باز کنید و فایل `index.html` را با دوبار کلیک در مرورگر باز کنید.
سایت کامل نمایش داده می‌شود.

> توصیه: چون فایل‌ها با مسیرهای نسبی خوانده می‌شوند، بهتر است سایت را از طریق یک
> وب‌سرور محلی باز کنید تا همه رفتارها (فونت، پارالاکس، دیالوگ‌ها) دقیقاً مثل هاست واقعی باشد.

### روش وب‌سرور محلی
در پوشه پروژه یکی از این دستورها را اجرا کنید و سپس در مرورگر `http://localhost:8000` را باز کنید:

```bash
# اگر پایتون نصب دارید
python3 -m http.server 8000

# یا با Node.js
npx serve .
```

## ۲. بارگذاری روی هاست (مثلاً هاست اشتراکی ایران)

۱. محتوای پوشه را (یعنی `index.html` و پوشه `assets/`) در پوشه ریشه هاست
(`public_html` یا `www`) آپلود کنید.
۲. ساختار پوشه‌ها را تغییر ندهید؛ همه مسیرها نسبی هستند.
۳. تمام. نیازی به تنظیمات سرور، دیتابیس یا نصب چیزی روی هاست نیست.

اگر سایت را در پوشه‌ای غیر از ریشه هاست می‌گذارید، هیچ تغییری لازم نیست؛ مسیرها نسبی‌اند.

## ۳. ساختار پروژه

```
/
  index.html                    صفحه اصلی سایت
  README.md                     همین راهنما
  dist/
    mehdi-parsa-website.zip     بسته کامل قابل آپلود
  assets/
    css/
      styles.css                پایه، توکن‌های رنگ، اجزای رابط
      responsive.css            چیدمان واکنش‌گرا (دسکتاپ، تبلت، موبایل)
      animations.css            انیمیشن ورود، عمق سه‌بعدی، احترام به کاهش حرکت
    js/
      main.js                   سربرگ چسبان، منوی موبایل، جست‌وجو، سال پاصفحه
      interactions.js           انیمیشن ورود بخش‌ها، دیالوگ خدمات و مقالات
      3d-effects.js             پارالاکس ملایم و چرخش سه‌بعدی کارت‌ها
    images/                     تصویرهای WebP سایت
      source/                   سورس SVG تصویرها + raster.js برای ساخت دوباره
    fonts/                      فونت وزیرمتن (۴ وزن، woff2، محلی)
    icons/
      logo.svg                  نشان برند
      favicon.svg               آیکون مرورگر
      icons.svg                 اسپرایت آیکون‌های رابط
```

## ۴. مواردی که باید با اطلاعات واقعی شما جایگزین شود

این موارد عمداً **جای‌نگهدار** هستند و هیچ اطلاعات ساختگی (مدرک، گواهینامه، سابقه کاری،
شماره تماس) در سایت نوشته نشده است. برای جایگزینی، فایل `index.html` را با یک ویرایشگر متن
باز کنید و عبارت‌های داخل کروشه را تغییر دهید:

| مورد | محل در `index.html` | مقدار فعلی |
| --- | --- | --- |
| شماره تماس | پاصفحه، بخش «تماس با من» | `[شماره تماس]` |
| نشانی ایمیل | پاصفحه، بخش «تماس با من» | `[نشانی ایمیل]` |
| نشانی محل فعالیت | پاصفحه، بخش «تماس با من» | `[نشانی محل فعالیت]` |
| مدرک تحصیلی | بخش «درباره من» | `[مدرک تحصیلی]` |
| گواهینامه بین‌المللی | بخش «درباره من» | `[گواهینامه بین‌المللی]` |
| سابقه کاری | بخش «درباره من» | `[سابقه کاری]` |
| تاریخ انتشار مقاله‌ها | کارت‌های مقالات | `[تاریخ انتشار]` |
| پیوند شبکه‌های اجتماعی | پاصفحه، آیکون‌های اجتماعی | پیوندهای `#` جای‌نگهدار |

همچنین در `assets/js/interactions.js`:
- متن معرفی هر خدمت (`SERVICES`) و متن نمونه مقاله‌ها (`ARTICLES`) قابل ویرایش است.
- متن‌های مقالات «نمونه» هستند تا چیدمان و خوانایی مشخص شود.

**دکمه‌های «رزرو مشاوره»** هیچ درخواستی ارسال نمی‌کنند: چون سامانه رزرو وجود ندارد، این دکمه‌ها
پنجره‌ای باز می‌کنند که راه‌های ارتباطی و توضیح وضعیت رزرو را نشان می‌دهد. پس از آماده شدن
یک فرم یا سامانه رزرو، می‌توانید این دکمه‌ها را به آن متصل کنید.

**دکمه پخش ویدئو** هم ویدئویی را شروع نمی‌کند (هنوز ویدئویی وجود ندارد) و فقط پنجره
توضیح وضعیت ویدئوها را باز می‌کند. پس از آماده شدن ویدئوها، پخش‌کننده را در بخش
«آموزش‌های ویدئویی» قرار دهید.

## ۵. تغییر تصویرها و فونت

- تصویرها در `assets/images/` قرار دارند و از سورس‌های SVG در `assets/images/source/` ساخته شده‌اند.
- برای جایگزینی با عکس واقعی: کافی است فایل WebP با همان نام (مثلاً `hero-specialist.webp`) را
  جای فایل فعلی بگذارید. اندازه‌های پیشنهادی در جدول زیر آمده است.

| فایل | اندازه پیشنهادی |
| --- | --- |
| `hero-specialist.webp` | ۸۸۰ × ۱۰۸۰ |
| `about-specialist.webp` | ۸۸۰ × ۱۰۸۰ |
| `service-*.webp` | ۸۰۰ × ۵۲۰ |
| `video-poster.webp` | ۱۴۰۰ × ۸۰۰ |
| `article-*.webp` | ۸۰۰ × ۵۰۰ |
| `consultation-banner.webp` | ۱۸۰۰ × ۵۲۰ |

- فونت وزیرمتن (وزن‌های ۴۰۰، ۵۰۰، ۶۰۰ و ۷۰۰) به‌صورت `woff2` داخل `assets/fonts/` ذخیره شده است
  و از هیچ سرویس فونت اینترنتی خوانده نمی‌شود.

## ۶. آزمون آفلاین

۱. اتصال اینترنت را قطع کنید.
۲. `index.html` را باز کنید.
۳. باید همه بخش‌ها، تصویرها، فونت فارسی و افکت‌های سه‌بعدی بدون خطا نمایش داده شوند.
   (در کنسول مرورگر هیچ خطای بارگذاری وجود ندارد، چون هیچ درخواست بیرونی‌ای ثبت نمی‌شود.)

---

## ۷. دسترس‌پذیری و کارایی

- ساختار معنایی (`header`, `main`, `section`, `footer`)، پیمایش با کیبورد، دکمه‌های واقعی،
  لینک پرش به محتوا، برچسب‌های ARIA و مدیریت فوکوس در پنجره‌ها.
- احترام به `prefers-reduced-motion`: همه انیمیشن‌ها و افکت‌های سه‌بعدی خاموش می‌شوند.
- افکت‌های سه‌بعدی روی صفحه‌های لمسی (موبایل/تبلت) غیرفعال می‌شوند تا کارایی حفظ شود.
- همه افکت‌ها با `transform` و `opacity` اجرا می‌شوند (بدون جابه‌جایی چیدمان).

## ۸. بسته تحویل

فایل `dist/mehdi-parsa-website.zip` شامل `index.html`، `README.md` و کل پوشه `assets/` است و
برای بارگذاری روی هاست آماده است (کافی است محتوای آن را از حالت فشرده خارج و آپلود کنید).
