| فایل | نوع | توضیح |

| `caffeino-menu.json` | صفحه | منوی آنلاین با ۲۵ آیتم و دسته‌بندی |
| `caffeino-events.json` | صفحه | مراسم و جشن‌ها |
| `caffeino-gallery.json` | صفحه | گالری تصاویر |
| `caffeino-reservation.json` | صفحه | فرم رزرو میز |
| `caffeino-about.json` | صفحه | درباره کافئینو |

## پیش‌نیازها

### افزونه‌های مورد نیاز

1. **Elementor** (نسخه ۳.۲۰ به بالا) — افزونه اصلی صفحه‌ساز
2. **Elementor Pro** (نسخه ۳.۲۰ به بالا) — برای فرم‌ها، هدر/فوتر Theme Builder و ویجت‌های پیشرفته
3. **فونت وزیرمتن** — از [cdn.jsdelivr.net](https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/) بارگذاری می‌شود (نیازی به نصب محلی نیست)

> بدون Elementor Pro، ویجت فرم (`Form`) و ویجت منوی ناوبری کار نخواهند کرد. سایر ویجت‌ها با نسخه رایگان Elementor قابل استفاده هستند.

## مراحل نصب

### مرحله ۱: نصب افزونه‌ها

۱. در پیشخوان وردپرس به **افزونه‌ها → افزودن** بروید.
۲. افزونه **Elementor** را جستجو و نصب و فعال کنید.
۳. افزونه **Elementor Pro** را از حساب کاربری خود دانلود و نصب و فعال کنید.

### مرحله ۲: افزودن CSS سفارشی

۱. به **المنتور → تنظیمات سایت** بروید.
۲. در بخش **Custom CSS** محتوای فایل `css/cafeino-custom.css` را کپی و پیست کنید.
۳. ذخیره کنید.

> اگر Elementor Pro ندارید، CSS را در **نمایش → سفارشی‌سازی → CSS اضافی** قرار دهید.

### مرحله ۳: افزودن JavaScript سفارشی

۱. به **المنتور → کد سفارشی** بروید.
۲. یک کد جدید با نوع "Header" ایجاد کنید.
۳. محتوای فایل `js/cafeino-custom.js` را کپی و پیست کنید.
۴. در همه صفحات فعال کنید.

> بدون Elementor Pro، از افزونه **Insert Headers and Footers** استفاده کنید.

### مرحله ۴: وارد کردن قالب‌های صفحه

برای قالب‌های **صفحه** (homepage، menu، events، gallery، reservation، about، contact):

۱. به **المنتور → قالب‌ها** بروید.
۲. روی دکمه **وارد کردن قالب** کلیک کنید.
۳. فایل JSON مورد نظر (مثلاً `caffeino-homepage.json`) را آپلود کنید.
۴. قالب وارد شده را در لیست قالب‌ها پیدا کرده و روی **ویرایش با المنتور** کلیک کنید.
۵. محتوای قالب را در صفحه مورد نظر کپی کنید (یا از آن به عنوان صفحه جدید استفاده کنید).
۶. برای هر فایل JSON این مراحل را تکرار کنید.

### مرحله ۵: وارد کردن هدر و فوتر (Theme Builder)

برای قالب‌های **هدر** و **فوتر**:

۱. به **المنتور → Theme Builder** بروید (نیاز به Elementor Pro).
۲. روی **افزودن جدید** کلیک کنید.
۳. نوع قالب را **Header** (برای هدر) یا **Footer** (برای فوتر) انتخاب کنید.
۴. در ویرایشگر المنتور، دکمه **افزودن از قالب** (پوشه) را بزنید.
۵. فایل JSON مربوطه را آپلود و وارد کنید.
۶. قالب را ذخیره و منتشر کنید.
۷. در بخش **Display Conditions** شرط نمایش را تنظیم کنید:
   - هدر: "All Site" (تمام سایت)
   - فوتر: "All Site" (تمام سایت)

## تصاویر

تمام تصاویر از **Unsplash** استفاده می‌شوند و URLهای آن‌ها مستقیماً در قالب‌ها قرار دارند. نیازی به آپلود محلی نیست، اما برای پایداری بیشتر پیشنهاد می‌شود:

۱. تصاویر را از فایل `assets/images.md` دانلود کنید.
۲. در کتابخانه رسانه وردپرس آپلود کنید.
۳. در ویرایشگر المنتور، URL تصویر را با URL محلی جایگزین کنید.

## محتوای پویا (داینامیک)

### منوی آنلاین
منو به صورت ثابت (Static) در قالب قرار دارد. برای پویا کردن:

- از **Custom Post Type** به نام "menu_item" استفاده کنید
- فیلدهای سفارشی: نام، توضیح، قیمت، تصویر، دسته‌بندی، پیشنهادی
- از ویجت **Posts** المنتور برای نمایش آیتم‌ها استفاده کنید
- با **Dynamic Tags** فیلدها را متصل کنید

### رزرو میز
فرم رزرو از ویجت Form المنتور Pro استفاده می‌کند. ارسال‌ها در:
**المنتور → ارسال‌های فرم** قابل مشاهده هستند.

### رویدادها
رویدادها به صورت ثابت در قالب هستند. برای پویا کردن:
- Custom Post Type "event" ایجاد کنید
- با ویجت Posts نمایش دهید

## محدودیت‌ها

- **اسلایدر هیرو**: اسلایدر تعاملی اصلی در نسخه المنتور به صورت تصویر ثابت نمایش داده می‌شود. برای اسلایدر واقعی از ویجت **Slider** یا افزونه **Revolution Slider** استفاده کنید.
- **ریلزهای ویدیویی**: کارت‌های ریلز با تصویر ثابت (پوستر) نمایش داده می‌شوند. برای پخش ویدیو، ویجت **Video** المنتور را جایگزین کنید.
- **فیلتر منو تعاملی**: فیلتر دسته‌بندی منو با HTML/JS سفارشی پیاده‌سازی شده است. برای فیلتر کامل، از Custom Post Type و ویجت Posts استفاده کنید.
- **اعتبارسنجی این قالب‌ها**: فایل‌های JSON از نظر ساختار و نحو (Syntax) معتبر هستند. تأیید نهایی فقط با وارد کردن واقعی در Elementor ممکن است.

## پشتیبانی

برای هر سوال یا مشکل در وارد کردن قالب‌ها:
۱. مطمئن شوید نسخه المنتور و المنتور Pro به‌روز هستند.
۲. کش وردپرس و مرورگر را پاک کنید.
۳. اگر خطای JSON دریافت کردید، فایل را دوباره از ZIP استخراج کنید.
