# کافئینو — نسخه HTML مستقل (Standalone HTML Export)

این پوشه شامل خروجی کامل و مستقل وب‌سایت **کافئینو** (کافه و رستوران فارسی، راست‌چین) به‌صورت
پروژه‌ای از فایل‌های ایستای HTML/CSS/JavaScript است. این خروجی بر اساس نسخه Next.js
پروژه ساخته شده و طراحی، رنگ‌ها، تایپوگرافی، چیدمان، متن فارسی و رفتارهای تعاملی را عیناً
حفظ می‌کند.

---

## ساختار پوشه‌ها

```
caffeino-html/
├── index.html                صفحه اصلی (Homepage)
├── pages/
│   ├── menu.html             منوی آنلاین
│   ├── gallery.html          گالری تصاویر
│   ├── reservation.html      رزرو آنلاین میز
│   ├── events.html           مراسم و جشن‌ها
│   ├── about.html            درباره ما
│   ├── contact.html          تماس با ما
│   └── reels.html            کلیپ‌ها و ریلزها
├── assets/
│   ├── css/
│   │   └── style.css         استایل‌های سفارشی (پورت از globals.css)
│   ├── js/
│   │   ├── icons.js          سیستم آیکن SVG (داخل‌خطی، بدون وابستگی)
│   │   ├── data.js           تمام داده‌ها (منو، ریلز، رویدادها، گالری، تماس)
│   │   └── main.js           هدر/فوتر، اسلایدر، منوی موبایل، اسکرول‌ریویل، تعاملات
│   ├── images/
│   │   └── favicon.svg       آیکن سایت (لوگوی کافئینو)
│   └── fonts/                (فونت Vazirmatn از CDN بارگذاری می‌شود — فایل محلی لازم نیست)
└── README.md                 همین فایل
```

## صفحه‌ها و امکانات بازتولیدشده

| صفحه | امکانات |
|------|---------|
| خانه (`index.html`) | اسلایدر هیرو (چندتصویری با کنترل و دات)، دسته‌بندی استوری، ریلزها، رزرو، درباره، گالری، اینستاگرام، تماس |
| منو (`menu.html`) | جستجو، فیلتر دسته‌بندی، کارت‌های محصول، مودال جزئیات (مواد اولیه و قیمت) |
| گالری (`gallery.html`) | فیلتر دسته‌بندی، چیدمان موزاییکی، لایت‌باکس تصویر |
| رزرو (`reservation.html`) | فرم رزرو با نام، تلفن، تاریخ، ساعت، تعداد نفرات، توضیحات + صفحه تأیید |
| مراسم (`events.html`) | کارت‌های رویداد با ظرفیت و امکانات |
| درباره (`about.html`) | تصویر هیرو، ویژگی‌ها، بخش داستان |
| تماس (`contact.html`) | اطلاعات تماس، شبکه‌های اجتماعی، فرم پیام، نقشه |
| ریلزها (`reels.html`) | کارت‌های ریلز، مودال پخش با پسندیدن/ذخیره/اشتراک/کپی‌لینک |

رفتارهای تعاملی: منوی موبایل کشویی، اسکرول‌ریویل (افکت ظاهرشدن هنگام اسکرول)،
سبک‌دهی هدر هنگام اسکرول، کارت‌های تعاملی ریلز.

## پیش‌نیازها

این پروژه فقط به یک مرورگر وب نیاز دارد. دو منبع خارجی به‌صورت CDN استفاده می‌شوند:

1. **Tailwind CSS (Play CDN)** — `https://cdn.tailwindcss.com` — برای بازتولید دقیق
   کلاس‌های ابزاری همانند نسخه اصلی. (تنظیمات رنگ/فونت/انیمیشن کافئینو داخل هر صفحه
   پیکربندی شده است.)
2. **فونت Vazirmatn** — از CDN `cdn.jsdelivr.net` — همان فونت نسخه اصلی.

> برای بارگذاری کامل نیاز به اتصال اینترنت دارید (مانند نسخه اصلی). تصاویر از
> Unsplash و نقشه از OpenStreetMap بارگذاری می‌شوند.

## اجرای محلی

هیچ build یا نصبی لازم نیست. کافی است فایل `index.html` را باز کنید:

### روش ۱: باز کردن مستقیم
فایل `index.html` را با مرورگر باز کنید. (در برخی مرورگرها Play CDN در پروتکل
`file://` ممکن است محدود شود — روش زیر مطمئن‌تر است.)

### روش ۲: سرور محلی (پیشنهادی)

با Python:
```bash
cd caffeino-html
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

با Node (در صورت نصب `npx`):
```bash
cd caffeino-html
npx serve .
```

با VS Code: افزونه **Live Server** را نصب کنید و روی `index.html` راست‌کلیک → "Open with Live Server".

## استقرار روی هاست (Deployment)

چون پروژه کاملاً ایستا است، روی هر هاست فایل ایستا قابل استقرار است:

### Netlify
1. پوشه `caffeino-html` را به مخزن Git پوش کنید (یا drag-and-drop کنید).
2. در Netlify: Build command خالی بگذارید، Publish directory را `caffeino-html` تنظیم کنید.

### Vercel
1. مخزن را وارد کنید.
2. Framework Preset: "Other"، Output Directory: `caffeino-html`، Build Command: خالی.

### GitHub Pages
1. پوشه `caffeino-html` محتویات را در شاخه `gh-pages` یا پوشه `docs/` قرار دهید.
2. در Settings → Pages منبع را روی آن شاخه تنظیم کنید.

### هاست اشتراکی / cPanel
تمام محتویات داخل `caffeino-html` را در پوشه `public_html` آپلود کنید.

### nginx
```nginx
server {
  listen 80;
  server_name cafeino.example;
  root /var/www/caffeino-html;
  index index.html;
  location / { try_files $uri $uri/ /index.html; }
}
```

## نکات و محدودیت‌ها

- **طراحی و چیدمان:** تمام رنگ‌ها، فاصله‌ها، تایپوگرافی، آیکن‌ها و چیدمان عیناً از
  نسخه اصلی پورت شده‌اند. فایل `assets/css/style.css` حاوی استایل‌های سفارشی
  (`.outer-frame`، `.input-field`، `.reveal`، اسکرول‌بار و …) است.
- **داده‌ها:** تمام داده‌ها در `assets/js/data.js` متمرکز هستند. برای تغییر منو،
  رویدادها، گالری یا اطلاعات تماس، این فایل را ویرایش کنید.
- **تصاویر:** از همان آدرس‌های Unsplash نسخه اصلی استفاده می‌شود (بدون تصاویر
  جایگزین یا مسیرهای شکسته).
- **فرم‌ها:** فرم‌های رزرو و تماس در مرورگر به‌صورت تأیید سمت‌کلاینت نمایش موفقیت
  می‌دهند و داده‌ها را ذخیره یا ارسال نمی‌کنند (مانند نسخه اصلی که backend نداشت).
  برای اتصال به سرویس واقعی (ایمیل/دیتابیس) باید یک بک‌اند یا سرویس فرم اضافه کنید.
- **نقشه:** نقشه تعبیه‌شده از OpenStreetMap است.
